# Exemplars

This directory preserves reference manuscripts that establish voice, density,
structure, and quality. An exemplar is provenance, not the normal editing
surface.

## Rules

- Do not move, rename, reformat, or revise an exemplar as part of ordinary entry
  work.
- Create a working copy under `entries/` and record the exemplar path and
  checksum in that copy's front matter.
- If an exemplar must ever be corrected, make the change explicit and update
  every recorded checksum that depends on it.
- Do not add YAML front matter to a preserved exemplar unless preservation
  policy is intentionally being changed.

# Developing Concepts

Place selected concepts here while testing mechanism, classification, history,
limitations, countermeasures, and canon dependencies.

A developing concept is not yet canon. Promote it to `entries/` only when it can
sustain a full historical and engineering reconstruction.

If the author deliberately promotes a small cross-entry fact before that point,
keep a **Canon integration status** ledger in the concept and link the real
process record under `docs/`. The ledger must say what became shared provisional
canon and what remains reserved; it does not make the whole concept canonical.

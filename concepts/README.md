# Concepts

Concept files are authorial development material, not in-world documents and not
canon. They let promising and rejected ideas remain legible without contaminating
the active Compendium.

## Lifecycle

- [`proposed/`](proposed/) contains unselected ideas.
- [`developing/`](developing/) contains ideas being actively tested.
- [`rejected/`](rejected/) contains deliberately retained dead ends and the
  reasons they were set aside.

Start with [`../templates/concept-brief.md`](../templates/concept-brief.md).

Moving a file between these directories records an editorial decision. It does
not require changing the fictional history because concepts are outside that
history until promoted into `entries/` or `canon/`.

# Assets

Store maps, diagrams, illustrations, insignia, and other non-manuscript material
here.

Recommended organization:

```text
assets/
├── entries/
│   └── a-7-01/
└── shared/
```

Use filenames that describe content and variant. Record source, creator, license,
and generation notes beside any asset that did not originate as ordinary
repository-authored text.

Rendered or generated assets are presentation material. The Markdown manuscript
and canon notes remain authoritative for wording and setting commitments.

# Documentation

These documents describe how the Compendium is organized and maintained.

- [`repository-structure.md`](repository-structure.md) defines the role and
  authority of every top-level directory.
- [`authoring-workflow.md`](authoring-workflow.md) describes the lifecycle from
  weapon idea to adopted entry.
- [`metadata-reference.md`](metadata-reference.md) defines entry front matter and
  controlled vocabulary.
- [`rzez-integration.md`](rzez-integration.md) records how the original Rzez
  exemplar was introduced into the new structure.

When documentation and an existing manuscript disagree, do not silently edit
the manuscript to match the documentation. Record the disagreement and decide
whether the schema, the manuscript, or both should change.
